# lovesong1950s assets

Public image assets for lovesong1950s.blogspot.com.

- `album-thumbnails/`: 1280x1280 square album covers used as Blogger list thumbnails.
  Blogger picks a post first image as its list thumbnail and crops it to a square, so a
  16:9 YouTube thumbnail comes back letterboxed. Each post carries one of these squares in
  a hidden div ahead of the visible 16:9 hero image.
